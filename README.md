# mnist_pytorch
我的第一个 PyTorch 项目：MNIST 手写数字识别，记录学习、训练与预测过程。接下来我会在这里分享我的启发和积累。
10.15
学会创建自己的github仓库，并且明白了之后新建文件和修改文件的步骤。
11.17
我把01_basic里面的pytorch_basic学习完成了
01.autograd.py是对一个设定好的参数y进行反向求导，算出对x,w,b的梯度
02.train_step.py是对一个x[10,3]进行模型预测去接近y[10,2]，求出预测值与实际值的损失函数以后对其反向求导，并之后optimizer.step()更新Linear[3,2]中的weight和bias，再对x进行一次模型预测，得到的值会更加靠近y
另外还学习了如何保存模型，复制到一个新的模型里面，两个预测结果一样
03.data.py是向MNIST已有的数据集里面一次取出一张（一批eg:32）图片，不过这个取出来的是image[(32),1,28,28],label[5,...,],之后还讲了如何自己创建一个自己的数据集，将来可以放自己想放的数据
04.pretrained model.py   将2中的模型换成ResNet模型
